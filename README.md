# Health+ Tracker

A minimal daily health tracker built with React and Vite.

## Features

- Log water intake, steps, sleep, weight, and mood for the day
- Progress rings against configurable daily goals
- 7-day trend charts for water, steps, sleep, and weight
- Recent activity log with delete support
- Data persists locally in the browser (`localStorage`) — nothing leaves your device

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run lint` — run ESLint
- `npm run preview` — preview the production build
